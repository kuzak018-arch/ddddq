# Dota Drafter

Помощник драфта Dota 2 для Windows 11: Tauri 2 + React/TypeScript (`app/`) и Python FastAPI (`backend/`).
Журнал этапов и все решения — в `PLAN.md`, устройство — в `README.md`.

## Как работаем
- Отвечать пользователю по-русски, коротко и по делу.
- Без заглушек: каждую часть проверять (тесты, проверка типов, по возможности живой запуск).
- После каждого законченного куска — запись в `PLAN.md` (что сделано, что проверено, что решено самостоятельно) и коммит.
- Никогда не коммитить `.env`, `secrets/` и `data/`.
- Правило безопасности игры: никакого чтения памяти Доты, инъекций и правки её файлов. Можно только конфиг GSI, захват картинки окна и открытые API (OpenDota, Stratz). Исключения, только по кнопке и только при закрытой Доте:
  - файл сеток героев `hero_grid_config.json` (Steam → userdata → 570 → remote → cfg): с резервной копией и слиянием, которое трогает лишь сетки с префиксом «Драфтер · » (`backend/drafter/hero_grid.py`, там же проверка и откат);
  - «Оформление игры» (выключено по умолчанию, включается после предупреждения о рисках): фон меню — наш `pakNN_dir.vpk` в `game/dota_<язык озвучки>/`, файлы игры не меняются, чужой пак с тем же именем не трогается; шрифт — замена файлов `game/dota/panorama/fonts/*.otf` с копией оригиналов в наши данные; «Свои VPK» — однофайловые `.vpk` пользователя туда же, где фон, под свободным `pakNN_dir.vpk` (не поверх чужих файлов, многотомные не принимаются); «Убрать всё» всё возвращает (`backend/drafter/game_mods/`). Настройки Доты (язык озвучки, параметры запуска) только читаются, никогда не меняются.

## Команды
```bash
# тесты бэкенда (из backend/)
python -m pytest -q tests
# проверка типов интерфейса (из app/)
npx tsc --noEmit -p .
# API для разработки и интерфейс в браузере
python -m drafter.api --port 47900     # из backend/
npm run dev                            # из app/, http://localhost:1420
```

## Что есть только на ПК пользователя
- `data/` (~300 МБ): база матчей OpenDota, обученная модель, константы, иконки, кэши Stratz. В облаке и на GitHub её нет, поэтому тесты, которым нужны данные, пропускаются (`skipif`): на чистой машине 81 проходит, остальные пропущены. Это нормально.
- `.env` с `STRATZ_TOKEN` и `DOTA_ACCOUNT_ID`. Без токена всё, что ходит в Stratz, отвечает «нет токена».
- Проверка вживую с Дотой (GSI, захват окна, оверлей) возможна только на ПК пользователя.
- Сборка установщика в облачной сессии невозможна (Linux). Его собирает GitHub Actions на Windows.

## Выпуск версии
Код и релизы приватные (`ddddq`). Обновления в приложении (Настройки → «Версия и обновления», по умолчанию автоматически) берутся из публичного репозитория только с установщиками `RELEASES_REPO` (по умолчанию `kuzak018-arch/dota-drafter-releases`): `backend/drafter/updates.py` скачивает и сверяет SHA-256, `app/src-tauri/src/update.rs` ставит поверх (`/P /UPDATE`).
1. Изменения в ветке → PR в `main` (проверка `check.yml`: тесты и `tsc`).
2. После слияния — тег `vX.Y.Z` (больше предыдущего): `git tag v1.0.1 && git push origin v1.0.1`.
3. `release.yml` на Windows собирает установщик `Dota Drafter_X.Y.Z_x64-setup.exe` и выкладывает его артефактом сборки (Actions → запуск Release → Artifacts, хранится 90 дней), прикрепляет к GitHub Release `vX.Y.Z` в `ddddq` (хранится всегда) вместе с `.sha256` и публикует в `RELEASES_REPO` для обновлений (нужен секрет `RELEASES_TOKEN`: fine-grained токен с Contents: read and write только на этот репозиторий; без него шаг пропускается с предупреждением). Описание версии — `release-notes/vX.Y.Z.md`. «Run workflow» без тега даёт только артефакт.
- Скачать новую версию: github.com/kuzak018-arch/ddddq → Releases → `vX.Y.Z` → `Dota.Drafter_X.Y.Z_x64-setup.exe` (GitHub меняет пробел в имени на точку) (нужен вход в GitHub: репозиторий приватный). Закрыть приложение и запустить установщик поверх старой версии: настройки и данные в `%LOCALAPPDATA%\DotaDrafter` сохраняются.
- Стартовые данные сборка берёт из релиза `seed-data` в `ddddq`. Без него сборка падает с подсказкой. Если менялись модель или данные Stratz, сначала на ПК пользователя: `scripts/publish-seed.ps1`.
- Плагин updater Tauri не используется (и подпись `TAURI_SIGNING_PRIVATE_KEY` не нужна): целостность — SHA-256 из выпуска по HTTPS.
