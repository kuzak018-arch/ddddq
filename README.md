# Dota Drafter

Помощник драфта Dota 2 для Windows 10/11:
- вероятность победы по драфту с объяснением, подбор героя под твою роль и баны;
- мета по рангу, страница героя, билды и предметы против вражеского драфта;
- кто выигрывает линию и графики линии по минутам;
- «Игры топов» — матчи Immortal, Divine+ и про на выбранном герое;
- профиль с разбором твоих матчей;
- оверлей поверх игры, Game State Integration и чтение драфта с экрана;
- редактор сеток героев и (по желанию) оформление меню Доты.

> Фанатский некоммерческий проект, не связан с Valve. Память игры не читается. Без твоего нажатия в папку Доты кладётся только официальный конфиг GSI (`cfg/gamestate_integration`). Только по кнопке и при закрытой Доте пишутся твои сетки героев (с резервной копией) и «Оформление игры» (выключено по умолчанию, «Убрать всё» всё возвращает). Данные: OpenDota, Stratz, Valve.

## Установка

1. Скачай установщик: github.com/kuzak018-arch/ddddq → Releases → `vX.Y.Z` → `Dota.Drafter_X.Y.Z_x64-setup.exe`. Репозиторий приватный, нужен вход в GitHub с доступом. Другу проще передать сам файл, см. «Дать программу другу».
2. Запусти его. Windows SmartScreen может предупредить о неизвестном издателе (установщик не подписан): «Подробнее → Выполнить в любом случае».
3. Новая версия ставится так же, поверх старой (сначала закрой программу, в том числе из трея). Настройки и данные в `%LOCALAPPDATA%\DotaDrafter` сохраняются. Автообновления нет.

## Первый запуск

Программа сама спросит:
1. **Steam ID** — Friend ID из профиля Доты (число вроде `1477734386`). По нему строятся твоя история и пул героев. В настройках Доты (раздел «Социальное») должны быть включены общедоступные данные матчей (Expose Public Match Data).
2. **Токен Stratz** — бесплатный: stratz.com/api → войти через Steam → скопировать токен. Без него не работают история матчей с оценкой, «Игры топов» Immortal/Divine и данные линий, а позиции и билды грубее. Токен хранится только у тебя в `.env`.
3. **Конфиг GSI** программа кладёт в папку Доты сама. После этого **перезапусти Доту** один раз.

Всё это можно поменять потом: «Настройки» (шестерёнка справа вверху) → «Аккаунт» и «Интеграция с игрой».

## Что настроить

- **Режим окна Доты — «Окно без рамки» или «В окне».** В эксклюзивном полноэкранном режиме оверлея не видно и захват окна не работает.
- **Оверлей:** `Ctrl+Shift+M` — показать или скрыть, `Ctrl+Shift+N` — сквозные клики (мышь проходит в игру). Клавиши меняются в «Настройки → Оверлей». Если клавиша занята в Доте, настройки об этом предупредят. Оверлей сам появляется, когда начинается выбор героев (по GSI).
- **Чтение драфта с экрана** включено сразу и калибровки не требует. Рамки берутся из встроенного профиля под разрешение окна и сами подгоняются по первым кадрам с героями. Программа вписывает героев на доску, а после каждого драфта учится на том, что в итоге стоит на доске (вписывай пропущенных героев и исправляй ошибки — это и есть обучение). Пока точность на твоих драфтах не подтверждена (2 драфта, 98%), чтение осторожное: вписывает только уверенно. Выключить можно в «Настройки → Чтение драфта с экрана»; там же «Проверить чтение» и ручные рамки на крайний случай.
- **Данные после патча:** «Настройки → Данные → Обновить данные после патча» докачивает матчи и переобучает модель (около 15 минут).
- **По желанию:**
  - «Настройки → Данные линий → Скачать пары моего пула» — чтобы и первое открытие линий было мгновенным;
  - «Оформление → Фон меню / Шрифт» — своё меню Доты; сначала прочитай предупреждение о рисках.

## Дать программу другу

1. Передай ему файл установщика (`Dota.Drafter_X.Y.Z_x64-setup.exe`). В нём нет твоих данных: ни Steam ID, ни токена, ни истории. Твои настройки лежат только у тебя в `%LOCALAPPDATA%\DotaDrafter`.
2. Друг ставит его и при первом запуске вводит **свой** Steam ID и **свой** токен Stratz. Один токен на двоих лучше не давать: лимиты запросов Stratz общие на токен.
3. Дальше как выше: перезапустить Доту и поставить «Окно без рамки».

Если что-то не работает:
- нет стадии драфта или героя — перезапусти Доту (GSI читается только при старте);
- пустой профиль — проверь Steam ID и общедоступные данные матчей в Доте;
- «нет токена Stratz» — «Настройки → Аккаунт»;
- логи — `%LOCALAPPDATA%\DotaDrafter\logs`.

Пользовательские данные: `%LOCALAPPDATA%\DotaDrafter` (`.env`, `data/`, `logs/`). Чтобы начать с чистого листа, закрой программу и удали эту папку (после удаления программы она может остаться).

## Разработка

Нужны Python 3.13, Node 22+, Rust (MSVC), WebView2.

```
python -m venv .venv
.venv\Scripts\pip install -r backend\requirements.txt
cd app
npm install
npm run tauri dev
```

`tauri dev` сам поднимает бэкенд из `.venv` на свободном порту со случайным токеном. Только бэкенд, со Swagger на http://127.0.0.1:47900/docs:

```
cd backend
..\.venv\Scripts\python -m drafter.api
```

| Команда (`cd backend`, `..\.venv\Scripts\python -m drafter.cli …`) | Что делает |
|---|---|
| `doctor` | проверка окружения, доступа к данным и настроек Доты |
| `constants` | герои, предметы, способности, патчи, иконки, русские описания Valve |
| `collect` | ранговые матчи All Pick текущего патча (OpenDota Explorer, можно прерывать) |
| `positions` / `train` | позиции героев (EM) и обучение модели с отчётом `reports/model.md` |
| `stratz` | позиции, баны, билды из Stratz для твоего брекета |
| `suggest`, `build`, `counter` | подсказки драфта и билды в консоли |
| `vision-synth`, `vision-eval` | проверка распознавания экрана, отчёт `reports/vision.md` |

Тесты: `cd backend` и `..\.venv\Scripts\python -m pytest -q`.

## Сборка установщика

```
.venv\Scripts\python -m PyInstaller backend\drafter-backend.spec --distpath build\backend\dist --workpath build\backend\work --noconfirm
cd app
npm run tauri build
```

PyInstaller собирает бэкенд в `build/backend/dist/drafter-backend/` вместе со стартовыми данными (константы, иконки, модель, Stratz). Tauri кладёт его в ресурсы и собирает установщик NSIS. Сырые матчи в установщик не входят: «Настройки → Обновить данные после патча» докачает их и переобучит модель.

На GitHub установщик собирает `.github/workflows/release.yml` по тегу `vX.Y.Z`: артефакт сборки и файл в GitHub Release `vX.Y.Z` этого (приватного) репозитория.

## Как устроено

- `backend/drafter`:
  - `data/` — OpenDota, Stratz, Valve, личная история;
  - `model/` — модель, подсказки, мета;
  - `builds/` — билды и правила против драфта;
  - `gsi.py`, `vision/` — интеграция с игрой и чтение экрана (`vision/layout.py` — раскладка драфта под любое разрешение);
  - `game_mods/` — «Оформление игры»: VPK, фон меню, шрифты, установка и откат;
  - `topgames.py` — «Игры топов»; `lane/` — линии;
  - `hero_grid.py` — файл сеток героев Доты: чтение для импорта, безопасная запись наших сеток («Драфтер · »), копии;
  - `api/` — FastAPI и общий драфт для всех окон.
- `app/` — Tauri 2 (Rust: запуск бэкенда, окно-оверлей, Acrylic, глобальные клавиши, свой значок окон, трея и ярлыков) и React + TypeScript (Liquid Glass).
  - `src/lib/grid/` — модель сетки Доты для редактора «Сетки»: холст 1193×593, раскладка карточек, ширины символов шрифта Radiance (`radiance.json`, делает `scripts/radiance-metrics.mjs`), арт из текста и картинок.
- `shared/` — русские имена и сленг, теги героев, правила предметов, шаблоны портретов для чтения драфта (`hero-templates/`), разметка меню и свободные шрифты для «Оформления игры».
