Разметка главного меню Dota 2 от Valve (© Valve Corporation), декомпилированная
(github.com/spirit-bear-productions/dota_vpk_updates), в том виде, в каком её хранит GridStudio
(github.com/linsisss/dota2-grid-toolkit, assets/dota-menu; версия клиента — в meta.json).
Фон меню кладёт в пак копии этих файлов со своими изменениями (backend/drafter/game_mods/menu.py).
После крупного обновления Доты их надо обновить из того же репозитория, иначе пак спрячет новые
элементы меню.
